### 题3. 判断 LL(1) 文法并构造分析表

$S \to aH$
$H \to aMd \mid d$
$M \to Ab \mid \varepsilon$
$A \to aM \mid e$

答：计算 FIRST 集和 FOLLOW 集：

| 非终结符 | FIRST 集 | FOLLOW 集 |
|---|---|---|
| $S$ | $\{a\}$ | $\{\#\}$ |
| $H$ | $\{a, d\}$ | $\{\#\}$ |
| $M$ | $\{a, e, \varepsilon\}$ | $\{d, b\}$ |
| $A$ | $\{a, e\}$ | $\{b\}$ |

验证 LL(1) 条件：
- $\text{predict}(H \to aMd) \cap \text{predict}(H \to d) = \{a\} \cap \{d\} = \varnothing$
- $\text{predict}(M \to Ab) \cap \text{predict}(M \to \varepsilon) = \{a, e\} \cap \{d, b\} = \varnothing$
- $\text{predict}(A \to aM) \cap \text{predict}(A \to e) = \{a\} \cap \{e\} = \varnothing$

所以该文法是 LL(1) 文法。LL(1) 分析表：

| | $a$ | $d$ | $b$ | $e$ | $\#$ |
|---|---|---|---|---|---|
| $S$ | $\to aH$ | | | | |
| $H$ | $\to aMd$ | $\to d$ | | | |
| $M$ | $\to Ab$ | $\to \varepsilon$ | $\to \varepsilon$ | $\to Ab$ | |
| $A$ | $\to aM$ | | | $\to e$ | |
